# AniGo production deployment

The [execution ledger](../../docs/deployment/2026-11-20-production-execution.md) records the actual deployment and acceptance limits. These files target the inspected Linux x64 shared host; app containers use host networking and bind **loopback only**. Caddy terminates public HTTPS. Do not publish app/SQL ports on wildcard addresses or broaden forwarded-header trust.

Run `bash scripts/deploy/publish.sh /absolute/new/artifacts-directory` from the repository root. It publishes Web/API/Worker and rejects environment configuration in the output. Copy the three output directories into a dedicated release's `artifacts/`, and copy this directory's Dockerfile, Compose file and Caddy fragment into that release. Add only the public SQL CA certificate as `artifacts/ca.crt`; never copy its private key into an image.

Create protected `runtime/Web.json`, `Api.json`, `Worker.json` from the empty example. Web/API require the same private `/data/photos` and `/data/keys` mounts. Set Production, exact AllowedHosts, the fixed recovery origin, verified sender, and provider keys using a secure local prompt/file. Application SQL connections use generated restricted logins, `Encrypt=True;TrustServerCertificate=False`, and the mounted server certificate must match `127.0.0.1`. Runtime and backup directories are ignored locally but must still use restrictive filesystem permissions. The example is deliberately incomplete and is not deployable configuration.

SQL needs `runtime/sql.env` (ACCEPT_EULA, MSSQL_PID, generated MSSQL_SA_PASSWORD, memory limit), `runtime/mssql.conf` (certificate/key paths, TLS 1.2 and force encryption), private `runtime/sql-tls/server.crt`/`server.key`, and an initially empty `data/sql` owned by container UID 10001. Use the licensed Express edition only within its capacity limits, or supply an appropriate production license. App files/photos/keys use UID 1654. SQL administrative credentials are deployment controls; applications use their own logins.

Back up the source with COPY_ONLY/CHECKSUM; verify locally, transfer over SSH, compare SHA-256 and verify on the destination. Obtain explicit approval for the exact new restore target. Restore **without REPLACE**; never overwrite another database or run startup migrations. Run CHECKDB and compare all restored table counts and the full schema contract. Keep the original backup and private-photo manifest. The separately created SmartFarmJobsDB receives the exact installed Hangfire SQL schema once, with QUOTED_IDENTIFIER enabled; runtime InitializeSchema stays false. Remove jobs setup ownership and grant its login SELECT/INSERT/UPDATE/DELETE/EXECUTE on HangFire only.

Use `docker compose up -d sql`, then `up -d web api` only when their prerequisites are ready. The Worker is deliberately behind the `worker` profile: enable its runtime settings and use `docker compose --profile worker up -d worker` after verifying the restored application DB and separate jobs schema. RunJobsOnStartup is normally false. Restart policies recover services after disconnect/restart; do not run `compose down -v` or delete data directories.

Back up `/etc/caddy` privately. Add only `anigo.caddy` and one import to a candidate main config, validate the complete candidate, verify the original has not changed, then reload Caddy. Retain rollback configuration and all existing sites/imports. Verify both public certificates, authenticated API/MVC reads, Worker outcomes, and existing sessions after restarting only AniGo services. A source-code rollback never implies a database rollback or permission to discard newer records.

Android release builds default to `https://api.anigo.website/`; the emulator debug URL remains unchanged. Production signing is an operator responsibility. A separate debug-signed release-mode application ID was used for physical-device acceptance to preserve the installed app and offline queue. Never package backend credentials in an APK.

Keep DB/photos/key-ring/runtime configuration backups together in protected off-host storage. Certificate renewal requires the protected private CA control key; inspect certificate expiry and renew before expiration. Renew provider credentials through their respective accounts. Deployment SSH/sudo/Cloudflare credentials belong outside application settings and Git.
