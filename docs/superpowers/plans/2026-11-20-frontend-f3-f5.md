## Design and boundaries
Reuse the approved 1024×768 / 4×3 WebP atlas byte-for-byte. Guide state comes from authorized current farm plots and crop statuses. Each state offers one existing destination; presentation dismissal/completion is scoped by actor/farm/stage, replay is explicit. No record mutation. Important alert selection uses backend ShouldInterrupt/read/ack/stale flags, never inferred emergencies. MVC calls shared services; Android Retrofit uses additive existing contracts. All new presentation fails closed on missing authorization or data.

Localization uses RESX and Android resources, persistent language choice and English fallback. Translate UI literals, never user data. Preserve farm-local DateOnly and UTC persistence. Recovery reuses secure backend service/routes with neutral request feedback. No framework migration, business-rule/schema changes or populated database writes.
